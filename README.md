# Dashboard Executivo para Oficina Automotiva

Projeto de Business Intelligence desenvolvido com Power BI, DAX e Excel para análise operacional e financeira de uma oficina automotiva.

## Objetivo

Transformar dados em informações para apoiar a tomada de decisão por meio de indicadores e visualizações interativas.

## Tecnologias Utilizadas

* Power BI
* DAX
* Power Query
* Microsoft Excel
* Business Intelligence

## Indicadores Desenvolvidos

* Receita Total
* Lucro Total
* Ticket Médio
* Quantidade de Ordens de Serviço
* Tempo Médio de Execução
* Margem de Lucro
* Taxa de Cancelamento

## Visualizações

* KPIs
* Receita por Categoria
* Receita por Marca
* Evolução da Receita
* Distribuição Geográfica dos Clientes
* Status das Ordens de Serviço

## Estrutura do Projeto

* `dados/` — Base de dados utilizada no projeto.
* `dashboard/` — Arquivo `.pbix`.
* `imagens/` — Capturas do dashboard.
* `documentacao/` — Documentação do projeto.
